# RENTAQ — All-In-One Property & Business Operating System

> *"Everything you manage. One place."*

**RENTAQ** is an intelligent, full-stack operating system for Indian accommodation, commercial, and property businesses.

---

## 🌟 Supported Property Categories
- **PG (Paying Guest Accommodations)**
- **Student & Working Hostels**
- **Hotels, Lodges & Guest Houses**
- **Villas & Homestays**
- **Serviced Apartments & Flats**
- **Independent Houses & Kothis**
- **Commercial Retail Shops**
- **Offices & Co-Working Desks**
- **Study Libraries & Reading Halls**
- **Modern Co-Living Suites**

---

## 🚀 Core Platform Modules

1. **Operations Center (Live Dashboard)**: Live KPIs for occupancy, beds, check-ins, check-outs, overdue payment alerts, and audit logs.
2. **Central Booking Inbox**: Multi-channel tracking across Booking.com, Airbnb, Agoda, MakeMyTrip, and Direct stay extensions with OTA platform commission reconciliation.
3. **RENTAQ Studio**: Ready-to-print House Rules posters, Room Number signs, Wi-Fi access cards, Payment UPI notices, and 11-month Tenancy Agreement templates.
4. **QR Code Generator Suite**: Instant QR generation for UPI payments, WhatsApp direct chat, Wi-Fi login, and Guest Self Check-In.
5. **Utility & Multi-Meter Management**: Multi-meter electricity/water tracking with auto-split calculators (Equal, Per Room, Per Bed, Pro-Rata by Days).
6. **Digital Guest Self Check-In Portal**: Public token-gated onboarding where guests submit Aadhaar, passport, receipts, and details before arrival.
7. **AI Virtual Receptionist & Multilingual Voice**: Powered by Gemini AI with live property database context, Indian language adaptation (13 languages), and owner-configured discount limits.
8. **Legal & Professional Services Marketplace**: Direct connections to certified lawyers (tenancy agreements, police verification guidance), CAs, and verified electricians/plumbers.
9. **Multi-User Organization RBAC**: Granular role-based permissions (Owner, Property Manager, Operations Manager, Receptionist, Landlord, Broker, Staff).
10. **Public Property Website Generator**: Auto-generated customer-facing storefront (`/p/:slug`) with photo highlights, amenities, house rules, and direct booking inquiries.

## 💻 Quick Start Guide

### Step 1: Install Dependencies
```bash
pnpm install
```

### Step 2: Start Development Servers
```bash
pnpm dev
```
- **Frontend**: http://localhost:5173/
- **API Server**: http://localhost:3001/api

*Database engine runs locally and persists data automatically in `.rentaq_pglite`.*
