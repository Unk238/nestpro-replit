# RENT TRACK V3 - GUEST SELF CHECK-IN PORTAL

## OBJECTIVE

Transform guest onboarding from a manual receptionist process into a self-service digital check-in experience.

The current Guest Management module behaves like a data entry form.

This is inefficient.

Instead, operators should generate a secure guest onboarding link and send it through:

* WhatsApp
* SMS
* Email

The guest should complete their own onboarding.

All information should automatically populate inside Rent Track.

---

# NEW MODULE

Guest Check-In Portal

This is a public-facing page.

Example:

renttrack.in/checkin/abc123

No login required.

Mobile-first design.

Optimized for WhatsApp opening.

---

# OPERATOR WORKFLOW

Inside Guest Manager:

Operator clicks:

Generate Check-In Link

System creates:

Unique Guest Registration Link

Example:

renttrack.in/checkin/abc123

Operator clicks:

Share via WhatsApp

System generates pre-filled WhatsApp message:

"Welcome to My Home PG.

Please complete your digital check-in using the link below.

https://renttrack.in/checkin/abc123"
